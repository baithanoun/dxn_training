## ملاحظات

- التصميم يدعم RTL بالكامل.
- التنقل السفلي يحتوي على: الرئيسية، التعلم، الفريق، ملفي.
- شاشات لوحة الإدارة موضحة بنسخة مصغرة للجوال؛ النسخة الكاملة تكون Web/Desktop.
