1.3 Learning Engine
FR-3.1: Session Generator: يبني lesson من 8-12 exercise بناءً على:

مهارات المستخدم الحالية (mastery levels)

أخطاء سابقة (spaced repetition — SM-2 algorithm)

difficulty target (يبدأ سهل ويصعب تدريجياً)

FR-3.2: تسجيل كل إجابة: {exercise_id, user_answer, is_correct, time_ms, timestamp}

FR-3.3: حساب mastery لكل skill: 0.0 → 1.0 (نموذج بسيط: weighted accuracy + recency)

FR-3.4: Hearts system: 5 قلوب، تُفقد عند الخطأ، تتجدد كل 4 ساعات (1 قلب) أو بـ gems

1.4 Gamification
FR-4.1: XP — يُمنح بعد كل lesson (10 XP عادي، +5 perfect، +2 combo)

FR-4.2: Streak — يُحسب حسب timezone المستخدم، freeze يشتري بـ gems

FR-4.3: Leaderboard أسبوعي — مجموعات 30 مستخدم (matching بـ XP tier)، يتجدد كل يوم أحد 00:00 UTC

6. Core Algorithms (Pseudocode)
6.1 Session Generator
text
function generateLesson(userId, lessonId):
    lesson = fetchLesson(lessonId)
    candidates = lesson.exercises          // pre-authored pool
    userMastery = getMastery(userId, lesson.skill_id)

    // 1. Prioritize exercises for skills due for review (SM-2)
    dueExercises = filter(candidates, ex =>
        hasSkillDueForReview(userId, ex.skill_tags))

    // 2. Order by difficulty (easy → hard, target 60-75% success rate)
    target = mapMasteryToDifficulty(userMastery)   // 1-10
    ordered = sortBy(candidates, ex => abs(ex.difficulty - target))

    // 3. Pick 10: 60% due-review, 30% new, 10% confidence builders
    selected = pickWithWeights(ordered, [0.6, 0.3, 0.1])

    // 4. Interleave types (no 2 same type in a row)
    return interleaveByType(selected)
6.2 Streak Update (Timezone-safe)
text
function onLessonComplete(userId, completedAt):
    user = getUser(userId)
    localDate = toDate(completedAt, user.timezone)  // YYYY-MM-DD
    stats = getStats(userId)

    if stats.last_lesson_date == localDate:
        // already counted today
        return stats

    yesterday = localDate - 1 day
    if stats.last_lesson_date == yesterday:
        stats.current_streak += 1
    else if hasActiveFreeze(userId, yesterday):
        consumeFreeze(userId, yesterday)
        stats.current_streak += 1
    else:
        stats.current_streak = 1

    stats.last_lesson_date = localDate
    stats.longest_streak = max(stats.longest_streak, stats.current_streak)
    save(stats)
    publishEvent('streak.updated', {userId, streak: stats.current_streak})
6.3 SM-2 Spaced Repetition
text
function updateMastery(userId, skillId, quality /* 0-5 */):
    m = getMastery(userId, skillId)  // {ease, interval, repetitions}

    if quality < 3:
        m.repetitions = 0
        m.interval = 1
    else:
        if m.repetitions == 0: m.interval = 1
        elif m.repetitions == 1: m.interval = 6
        else: m.interval = round(m.interval * m.ease)
        m.repetitions += 1

    m.ease = max(1.3, m.ease + 0.1 - (5 - quality) * (0.08 + (5 - quality) * 0.02))
    m.next_review = now() + m.interval days
    m.mastery = clamp(quality / 5, 0, 1)
    save(m)

6.5 Hearts Regeneration

// Lazy evaluation (no cron needed):
function getCurrentHearts(userId):
    stats = getStats(userId)
    if stats.hearts >= 5: return 5
    elapsed = now() - stats.hearts_refilled_at
    regen = floor(elapsed / 4h)
    return min(5, stats.hearts + regen)

// On heart loss:
function consumeHeart(userId):
    current = getCurrentHearts(userId)
    if current == 0: throw HEARTS_EXHAUSTED
    setHearts(userId, current - 1, refill_anchor=now())

10. Security Requirements
المجال	المتطلب
Auth	JWT RS256، access 15min، refresh 30d rotating (one-time use)
Authorization	RBAC: user, content_editor, admin
Rate Limiting	Redis: 60 req/min per user، 10/min على /auth/*
Input Validation	Whitelist + strict typing على كل endpoint
PII	تشفير على مستوى column (email, device tokens)
Anti-cheat	server-side validation لكل answer (لا trust على client) + حد أقصى XP/دقيقة
Secrets	AWS Secrets Manager / Doppler، ممنوع في git
GDPR	/me/export (JSON dump) + /me delete مع purge بعد 30 يوم

نفّذ DB migrations بحسب section 4 بالترتيب: users → content → progress → gamification.

unit test

Core algorithms (section 6) تُنفّذ كـ services معزولة مع unit tests قبل أي integration.

Flutter: ابدأ بـ features/learning/domain/exercise.dart (sealed class) قبل أي UI.

كل feature خلف feature flag — لا تطلق شيئاً مفعّل 100% من أول commit.

لا تبنِ microservices، GraphQL، أو Kubernetes — هذه قرارات مرفوضة صراحةً (section 3.2).

Definition of Done لأي PR: كود + test + event + flag + metric + documentation delta.
